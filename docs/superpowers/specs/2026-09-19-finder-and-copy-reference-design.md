# 在 Finder 中显示、复制代码引用

**日期**：2026-09-19
**状态**：已确认
**基线**：当前主分支

## 范围

| 切片 | 做什么 | 不做 |
|------|--------|------|
| Finder | 中栏文件右键「在 Finder 中显示」 | 侧栏仓库、选打开用的应用、用 git show 打开已删文件 |
| 复制引用 | 选区/当前行复制 ` ```path:start-end ` 围栏，可裁剪 | 改 Cmd+C、自定义粘贴板类型 |

约束沿用计划三：最低 macOS 15、鼠标可达、主线程不跑 git。

## Finder

- 中栏文件右键始终出现。第一项「在 Finder 中显示」。
- `NSWorkspace.activateFileViewerSelecting`，路径为当前 worktree + `FileStatus.path`。
- 右键点在已选集合里则揭示整组，否则只揭示这一行。
- 磁盘上不存在的路径跳过；一个都没有则 `cannotOpenFile`。
- 双击仍用默认应用打开。

## 复制代码引用

- Cmd+C 仍走 `copyableString`（去 gutter、留 +/-）。
- 新动作「复制代码引用」：右键、选区旁按钮（与「解释这段」并排）、`Cmd+Shift+C`。
- 无拖选时复制光标所在行。空文档不写剪贴板。
- 格式：` ```path:280-291 `，单行 `path:280`。仓库相对路径。行号取对应栏：右栏/统一视图用新侧，左栏用旧侧。
- 连续滚动跨文件拆成多个围栏。超过 80 行或 8000 字符保留开头，末尾 `… (truncated, N more lines)`。
