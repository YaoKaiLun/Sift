## 侧栏

- `state.json` 增加 `pinnedRepositoryPaths: [String]`（仓库根路径）。书签数组仍按**当前显示顺序**保存。
- 显示顺序恒为：置顶组（组内可拖）+ 未置顶组（组内可拖）。
- 新增仓库：`isPinned = false`，插入到第一个未置顶位置（即全部置顶之后、其余未置顶之前）。
- 恢复书签：必须按书签顺序 **append**，再套上置顶标记并 `normalize`。若走「插到置顶后」，多次恢复会把顺序反转。
- 右键：「置顶仓库」/「取消置顶」。置顶的仓库行显示图钉。
- 拖到某行：以该行是否置顶作为被拖仓库的新置顶状态，再 normalize。落点在行上半插入其前、下半插入其后。

## 放弃修改

- `git restore --worktree -- <paths>`，只动工作树，index 不动。
- 仅未暂存分组里、已跟踪且 `worktreeStatus != unmerged` 的文件。多选时只处理符合条件的子集。
- 无确认。未跟踪继续走「删除文件」确认框。

## 双击打开

- 单击仍是选择（含 Shift / Cmd 多选）。
- `clickCount == 2` 时 `NSWorkspace.shared.open(worktree/path)`。文件不存在则提示，不打开。

## diff 查找

- `NSTextView.usesFindBar = true`，增量搜索打开。
- 菜单「查找…」+ Cmd+F + 右栏栏头放大镜，都发同一通知，让当前 diff 文本视图成为 first responder 并 `showFindInterface`。
