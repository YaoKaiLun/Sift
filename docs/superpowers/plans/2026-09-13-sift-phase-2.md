# Sift 计划二 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在计划一阅读器上接上审查写操作、分栏与高亮、AI 解释、连续滚动和 blame，每一刀结束应用都能用。

**Architecture:** 写操作进 `GitKit`（`PatchBuilder` + `GitRepository` 写方法），经 `RepoStore` 调；高亮是 Foundation-only 的 `Highlighter`，只返回 token 区间；AI 是 `AIClient` 的 SSE 客户端。diff 仍是「一篇 NSAttributedString」，gutter 用自定义属性标记，高亮和复制都按属性跳过。`GitRunner` 增加 stdin 与 `optionalLocks`：写操作必须拿 index 锁，读操作继续 `GIT_OPTIONAL_LOCKS=0`。

**Tech Stack:** Swift 6、SwiftPM、SwiftUI 外壳、AppKit NSTextView、FSEvents、Keychain、XCTest。零第三方依赖。

**规格：** `docs/superpowers/specs/2026-09-13-sift-phase-2-design.md`

## Global Constraints

- 最低系统版本：macOS 26。
- 零第三方依赖。不引入 tree-sitter。
- **主线程上永不调用 git。** 写操作同样走 `GitRunner` + `Task.detached`。
- **写操作必须拿 index 锁。** `git add` / `git apply --cached` / `git restore --staged` 调用时 `optionalLocks: false`。读操作继续 `optionalLocks: true`（默认）。
- **永不轮询。** FSEvents 100ms 抖动窗口保留。写成功后立刻 `refreshFileList()`，不等 FSEvents。
- **切换即取消读任务。** 写操作不取消：同一时刻只允许一个在途写，写进行中再点按钮直接忽略。
- 语法高亮只改属性，不重建 text storage，不重置滚动。
- 所有操作鼠标可达。未跟踪文件 discard 是全应用唯一确认框。
- 性能门禁数字不放宽。`./Scripts/preflight.sh` 必须继续通过。
- 注释与提交说明用中文，与仓库现有风格一致。
- 不在 `main` 上实现。当前分支是 `feat/review-ops`。用户明确要求**不要**再开 worktree，就在该分支上改。
- 本计划按切片 A→D 顺序。不要提前做后面切片的 UI。

```swift
import Foundation

public enum PatchFileKind: Sendable, Equatable {
    case modified
    case added
    case deleted
}

public enum PatchBuilder {
    public static func build(
        hunk: Hunk,
        path: String,
        originalPath: String? = nil,
        kind: PatchFileKind
    ) -> String {
        let oldPath = originalPath ?? path
        let gitLine: String
        let oldHeader: String
        let newHeader: String
        switch kind {
        case .modified:
            gitLine = "diff --git a/\(oldPath) b/\(path)"
            oldHeader = "--- a/\(oldPath)"
            newHeader = "+++ b/\(path)"
        case .added:
            gitLine = "diff --git a/\(path) b/\(path)"
            oldHeader = "--- /dev/null"
            newHeader = "+++ b/\(path)"
        case .deleted:
            gitLine = "diff --git a/\(path) b/\(path)"
            oldHeader = "--- a/\(path)"
            newHeader = "+++ /dev/null"
        }
        var text = gitLine + "\n" + oldHeader + "\n" + newHeader + "\n" + hunk.patchText
        if !text.hasSuffix("\n") { text += "\n" }
        return text
    }
}
```


约定：
- `stage(path:)` → `git add -- <path>`，`optionalLocks: false`。
- `unstage(path:)` → `git restore --staged -- <path>`，`optionalLocks: false`。
- `apply` → `git apply`，按 flags 加 `--cached` / `-R`，stdin 为 patch UTF-8，`optionalLocks: false`。
- `deleteUntracked` 用 `FileManager.removeItem`，路径必须是 `root` 的相对路径且解析后仍在 `root` 下（防止 `../`）。不调 git。
- hunk 三个方法内部调 `PatchBuilder.build` + `apply`。`stage` = cached+!reverse；`unstage` = cached+reverse；`discard` = !cached+reverse。

```swift
public private(set) var isMutating = false

public func stage(file: FileStatus) async { await mutate { try await $0.stage(path: file.path) } }
public func unstage(file: FileStatus) async { await mutate { try await $0.unstage(path: file.path) } }
public func deleteUntracked(file: FileStatus) async {
    await mutate { try await $0.deleteUntracked(path: file.path) }
}
public func stage(hunk: Hunk) async {
    guard let file = selectedFile else { return }
    await mutate {
        try await $0.stage(hunk: hunk, path: file.path,
                           originalPath: file.originalPath,
                           kind: patchKind(for: file))
    }
}
// unstage(hunk:) / discard(hunk:) 同样

private func patchKind(for file: FileStatus) -> PatchFileKind {
    if file.isUntracked { return .added }
    if selectedFileIsStaged {
        if file.indexStatus == .added { return .added }
        if file.indexStatus == .deleted { return .deleted }
    } else {
        if file.worktreeStatus == .added { return .added }
        if file.worktreeStatus == .deleted { return .deleted }
    }
    return .modified
}

private func mutate(_ body: @escaping (GitRepository) async throws -> Void) async {
    guard !isMutating, let worktree = selectedWorktree else { return }
    isMutating = true
    defer { isMutating = false }
    let path = selectedFile?.path
    let repository = GitRepository(root: worktree.path)
    do {
        try await body(repository)
        if let path {
            await engine.invalidate(worktreePath: worktree.path, filePath: path)
        }
        await refreshFileList()
    } catch {
        errorMessage = "无法完成操作：\(error)"
    }
}
```
