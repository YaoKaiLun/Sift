# Sift 计划三 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修好转分隔线命中，并加上键盘切文件、后缀过滤、未推送 commit 阅读、GitHub Release 检查更新；每一刀结束应用都能用。

**Architecture:** 分栏热区提到 `ContentView` 的 overlay，不再靠 1pt 父框溢出命中。过滤是 `DiffEngine.FileFilter` 纯函数，中栏与连续滚动共用可见列表。未推送 commit 挂在左栏 worktree 下；点某条后中栏加载该 SHA 的文件与 message，`DiffCacheKey` 用 `DiffSide.commit(sha)` 和工作区缓存隔离。更新是新建的 `UpdateKit`（Foundation-only），UI 不进 `RepoStore`。

**Tech Stack:** Swift 6、SwiftPM、SwiftUI 外壳、AppKit `NSEvent` monitor / `NSTextView`、FSEvents、`URLSession`、`hdiutil`、XCTest。零第三方依赖。

**规格：** `docs/superpowers/specs/2026-09-14-sift-phase-3-design.md`

## Global Constraints

- 最低系统版本：macOS 26。
- 零第三方依赖。不引入 Sparkle。
- **主线程上永不调用 git，也不发网络请求。**
- **永不轮询 git。** 更新检查只在启动（Release）和菜单「检查更新」时发生。
- **切换即取消读任务。**
- 所有操作鼠标可达。方向键只是加速。
- 性能门禁数字不放宽。`./Scripts/preflight.sh` 必须继续通过。
- 注释与提交说明用中文。
- 未跟踪文件 discard 仍是全应用唯一确认框。未推送视图禁止 stage / discard。

```swift
import CoreGraphics

enum SplitOverlayLayout {
    static func hitMinXs(showsSidebar: Bool, sidebarWidth: CGFloat,
                         fileListWidth: CGFloat, hitWidth: CGFloat = 11)
        -> (sidebar: CGFloat?, fileList: CGFloat) {
        let half = hitWidth / 2
        let fileListBoundary = (showsSidebar ? sidebarWidth : 0) + fileListWidth
        return (
            showsSidebar ? sidebarWidth - half : nil,
            fileListBoundary - half
        )
    }
}
```

### Task 3: FileFilter 纯函数

**Files:**
- Create: `Sources/DiffEngine/FileFilter.swift`

**Interfaces:**
- Produces:

```swift
public enum FileFilter: Sendable {
    public static let defaultPatterns: [String]
    public static func matches(path: String, patterns: [String]) -> Bool
    public static func hiding<T>(_ items: [T], path: (T) -> String,

```

- [ ] **Step 1: 写失败的测试**

```swift

@testable import DiffEngine

final class FileFilterTests: XCTestCase {
    func testImageSuffix() {
        XCTAssertTrue(FileFilter.matches(path: "docs/shot.PNG", patterns: ["*.png"]))
        XCTAssertFalse(FileFilter.matches(path: "src/App.ts", patterns: ["*.png"]))
    }

    func testTestFileGlobs() {
        XCTAssertTrue(FileFilter.matches(path: "FooTest.swift", patterns: ["*Test.swift"]))
        XCTAssertTrue(FileFilter.matches(path: "a.spec.ts", patterns: ["*.spec.ts"]))
        XCTAssertFalse(FileFilter.matches(path: "Foo.swift", patterns: ["*Test.swift"]))
    }

    func testDirectorySegment() {
        XCTAssertTrue(FileFilter.matches(path: "src/fixtures/a.json", patterns: ["fixtures/"]))
        XCTAssertFalse(FileFilter.matches(path: "src/fixture-data/a.json", patterns: ["fixtures/"]))
    }

    func testHidingDisabledKeepsAll() {
        let paths = ["a.png", "b.ts"]
        XCTAssertEqual(
            FileFilter.hiding(paths, path: { $0 }, enabled: false, patterns: ["*.png"]),
            paths)
    }

    func testHidingDropsMatches() {
        XCTAssertEqual(
            FileFilter.hiding(["a.png", "b.ts"], path: { $0 },

            ["b.ts"])

}
```

```swift
public func unpushedCommits() async throws -> [CommitInfo]? {
    let up = try await runner.runAllowingFailure(
        ["rev-parse", "--abbrev-ref", "--symbolic-full-name", "@{upstream}"], in: root)

public func commitFiles(sha: String) async throws -> (
    files: [FileStatus], lineStats: [String: LineStats]
) {
    var nameArgs = ["diff-tree", "--no-commit-id", "--name-status", "-z", "-r"]
    var numArgs = ["diff-tree", "--no-commit-id", "--numstat", "-z", "-r"]

        nameArgs.append("--root")
        numArgs.append("--root")
    }
    nameArgs.append(sha)
    numArgs.append(sha)
    async let names = runner.run(nameArgs, in: root)
    async let nums = runner.run(numArgs, in: root)
    return (try NameStatusParser.parse(try await names), NumstatParser.parse(try await nums))
}

public func diff(path: String, from parent: String?, to sha: String) async throws -> FileDiff {
    let args: [String]

        args = ["diff", "--no-color", "-U3", parent, sha, "--", path]
    } else {
        args = ["show", "--format=", "--no-color", "-U3", sha, "--", path]
    }
    return DiffParser.parse(try await runner.run(args, in: root), path: path)
}
```
